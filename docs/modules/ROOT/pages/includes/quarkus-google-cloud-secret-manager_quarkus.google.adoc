[.description]
--
Enable Google Cloud access token authentication for the Secret Manager service.

When this property is not set, the value of `quarkus.google.cloud.access-token-enabled` is used.

Disable this property when the Secret Manager client must use the configured service account or the application default credentials, even if access token authentication is enabled globally.
